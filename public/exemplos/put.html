PUT Editar aluno

O método PUT serve para substituir um registro que já existe. O id vai na URL e os dados novos vão no corpo, como no POST.

O fluxo comum numa tela de edição é: 1) buscar o aluno com GET e preencher o formulário, 2) o usuário altera, 3) enviar tudo de volta com PUT.

1. Escolha o aluno

Os alunos de 1 a 5 são exemplos protegidos (a API responde 403). Cadastre o seu na página do POST e use o id dele aqui.
