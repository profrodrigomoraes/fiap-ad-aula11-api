Códigos de status

CódigoSignificadoQuando acontece
200OKDeu certo (GET, PUT, PATCH, DELETE)
201CreatedAluno criado com POST
400Bad RequestJSON mal formatado, campo faltando ou inválido, id que não é número
403ForbiddenChave errada no /reset
404Not FoundNão existe aluno com esse id, ou a rota não existe
405Method Not AllowedMétodo que a rota não aceita (ex: POST em /alunos/1)
409ConflictJá existe um aluno com esse e-mail
500Internal Server ErrorErro no servidor (não é culpa sua!)

Todo erro responde um JSON com a chave erro explicando o problema (e às vezes detalhes):

{ "erro": "Dados inválidos.", "detalhes": ["\"email\" é obrigatório e deve ser um e-mail válido, ex: \"ana@email.com\"."] }
